# IMPORTS.txt: which directory's files may import which. Read by scripts/check.py, step "imports".
# "A : B C": apart from Lean, Mathlib and its companion packages, a file under A/ imports only files
# under A/, B/ and C/. "A/X.lean : M N -K" or "A/* : M": those files may also import exactly the
# modules M and N, and may not import K or what is below it. "A/Dir/* : M.*": those files, and no
# other file of A, may import and reach M and what is below it. The lines also apply to what a file
# reaches through other files of the library: what a line allows its files to import, another file
# of A may reach only if it reaches such a file and that file reaches the module. A line that cannot
# mean what it seems to say fails the step: an entry that is no module name (a blank behind a minus
# makes two), ".*" or "-" where they have no meaning, a line for files that hits no file, "-K" with
# no module at or below K, an exact name at or below an "M.*" of the same directory.
