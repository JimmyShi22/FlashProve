# Words for OnBytes

Terms: [TERMS.md](../TERMS.md). Every other word of this folder's pages and comments is on
[lean/GLOSSARY.md](../GLOSSARY.md).

**Standard conditions** (docs: the requirements of the *standard parameter form* that concern the
configuration; that form also covers the call): named conditions that the public files must meet
before any call can pass: for example, that attention is proved (said of the provider's proof, not
of Lean: the parameter file's line `prof` is 20, that is profile 4, so that a proof has an attention
sub-proof for each group of layers; `Shape.p4`, Model/LayerLayout.lean; `cp_verify` refuses another
profile outright: [LIMITS.md](LIMITS.md), point 16), that both clamps are on, and that the
committer's files rest on one of the accounting's two sources ([LIMITS.md](LIMITS.md), point 11):
the proved lemma, or the theorem on codes (Theorem 4.6 of the full version, ePrint 2025/2055, of the
paper by Ben-Sasson, Carmon, Haböck, Kopparty and Saraf published at STOC 2026), which the
accounting takes as given (see "theorem on codes" in [lean/GLOSSARY.md](../GLOSSARY.md)). If one is
missed, the best possible result is `NOT-A-VERIFICATION`, or `NOT CHECKED` where this program does
not support the file ([LIMITS.md](LIMITS.md), point 19).

**Small examples**: see [LIMITS.md](LIMITS.md), "The files".
